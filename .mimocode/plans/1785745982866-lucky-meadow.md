# TradingAgents Web Platform - Architecture Plan

## Project Overview
Build a full-featured web platform for TradingAgents - a multi-agent LLM financial trading framework. The platform will allow users to run AI-powered stock/crypto analyses through a web interface with subscription-based access tiers.

**New project location**: `/home/nima/Workspace/trading-agents-platform/`

---

## Tech Stack

| Layer | Technology | Purpose |
|-------|-----------|---------|
| Frontend | Next.js 14+ (App Router) | SSR, routing, React Server Components |
| UI Components | shadcn/ui + Tailwind CSS | Consistent, accessible design system |
| Backend API | Next.js API Routes + Server Actions | Main API layer |
| Python Worker | FastAPI microservice | Wraps TradingAgents execution |
| Database | PostgreSQL + Prisma ORM | User data, subscriptions, analysis history |
| Cache/Queue | Redis + BullMQ | Job queue for long-running analyses |
| Auth | NextAuth.js (Auth.js v5) | Email/password + OAuth providers |
| Real-time | Server-Sent Events (SSE) | Analysis progress streaming |
| Containerization | Docker Compose | Local dev + production deployment |

## Database Schema (Prisma)

```prisma
// Core models
model User {
  id            String    @id @default(cuid())
  email         String    @unique
  name          String?
  passwordHash  String?
  image         String?
  role          Role      @default(USER)
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  subscription  Subscription?
  analyses      Analysis[]
  usageRecords  UsageRecord[]
  apiKeys       ApiKey[]
}

model Subscription {
  id                String    @id @default(cuid())
  userId            String    @unique
  user              User      @relation(fields: [userId], references: [id])
  plan              Plan      @default(FREE)
  status            SubStatus @default(ACTIVE)
  paymentProvider   String?   // "nowpayments" | "zarinpal" | "manual"
  externalSubId     String?   // Provider's subscription ID
  currentPeriodStart DateTime @default(now())
  currentPeriodEnd  DateTime
  cancelAtPeriodEnd Boolean   @default(false)
  createdAt         DateTime  @default(now())
  updatedAt         DateTime  @updatedAt
}

model Analysis {
  id            String       @id @default(cuid())
  userId        String
  user          User         @relation(fields: [userId], references: [id])
  ticker        String
  assetType     AssetType    @default(STOCK)
  tradeDate     DateTime
  status        AnalysisStatus @default(PENDING)
  decision      String?      // Buy/Sell/Hold/Overweight/Underweight
  
  // Reports stored as JSON
  marketReport      String?   @db.Text
  sentimentReport   String?   @db.Text
  newsReport        String?   @db.Text
  fundamentalsReport String?  @db.Text
  investmentPlan    String?   @db.Text
  traderProposal    String?   @db.Text
  finalDecision     String?   @db.Text
  
  // Config used
  llmProvider       String
  deepThinkModel    String
  quickThinkModel   String
  debateRounds      Int
  
  // Metadata
  startedAt     DateTime?
  completedAt   DateTime?
  errorMessage  String?    @db.Text
  tokensUsed    Int?       @default(0)
  costEstimate  Float?     @default(0)
  
  createdAt     DateTime   @default(now())
  
  @@index([userId, createdAt])
  @@index([ticker])
}

model UsageRecord {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  action      String   // "analysis" | "export" | "api_call"
  ticker      String?
  tokensUsed  Int      @default(0)
  cost        Float    @default(0)
  createdAt   DateTime @default(now())
  
  @@index([userId, createdAt])
}

model ApiKey {
  id        String   @id @default(cuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  key       String   @unique
  name      String
  isActive  Boolean  @default(true)
  lastUsed  DateTime?
  createdAt DateTime @default(now())
}

enum Role { USER | ADMIN }
enum Plan { FREE | PRO | ENTERPRISE }
enum SubStatus { ACTIVE | CANCELLED | PAST_DUE | TRIALING }
enum AssetType { STOCK | CRYPTO }
enum AnalysisStatus { PENDING | RUNNING | COMPLETED | FAILED | CANCELLED }
```

## Key API Endpoints

### Analysis
```
POST   /api/analysis              - Create new analysis
GET    /api/analysis              - List user's analyses
GET    /api/analysis/[id]         - Get analysis details
DELETE /api/analysis/[id]         - Cancel analysis
GET    /api/analysis/stream/[id]  - SSE stream for progress
```

### Billing
```
GET    /api/billing/subscription  - Get current subscription
POST   /api/billing/subscription  - Create/update subscription
POST   /api/billing/cancel        - Cancel subscription
GET    /api/billing/invoices      - Get invoice history
POST   /api/billing/webhook       - Payment provider webhook
```

### Usage
```
GET    /api/usage                 - Get current period usage
GET    /api/usage/history         - Get usage history
```

### User
```
GET    /api/user/profile          - Get user profile
PATCH  /api/user/profile          - Update profile
GET    /api/user/api-keys         - List API keys
POST   /api/user/api-keys         - Create API key
DELETE /api/user/api-keys/[id]    - Revoke API key
```
